# Explicar código

- Explica primero el propósito general y después los pasos importantes.
- Basa la explicación únicamente en el código y contexto disponibles.
- Si faltan archivos o información necesarios, indica qué no se puede confirmar.
- Señala posibles efectos secundarios o errores solo cuando haya evidencia.
